## EX-01 DINOv2 base LoRA 1022

**설계일:** 2026-10-17

**상태:** 12/30 epoch에서 중단 · val 평가 완료

사진 전체를 보는 DINO 분류기가 normal / heel / outsole / both를 얼마나 구분하는지 확인합니다. 향후 YOLO·DETR 및 앙상블과 비교할 첫 기준 실험입니다. 518 입력이나 다른 백본보다 우수하다고 가정하지 않습니다.

**사용자 결정 (2026-10-17):** DINOv2 + LoRA, 1022 입력, 30 epoch. 균형 정확도를 핵심 지표로 하고, 전체 정확도·클래스별 재현율을 함께 봅니다. 출력은 4×4 혼동 행렬과 지표 요약 표입니다.

아래는 설계값과 본 학습에 사용한 설정입니다. 128장 GPU 점검 후 실행 조합을 고정했습니다. 학습 중 설정이 바뀌면 별도 실험으로 구분합니다. 최신 상태와 완료 후 결과는 문서 끝의 실제 실행 기록에 자동 반영됩니다.

## EX-02 계획: DINOv3 ViT-B/16 LoRA

**기록일:** 2026-10-18

**상태:** 계획 · 15 epoch만 사용자 확정, 모델과 나머지 설정은 추천

EX-01의 DINOv2 결과를 기준으로 백본을 바꿨을 때의 성능을 확인합니다. 특히 normal을 손상으로 오판하는 문제가 줄어드는지 봅니다. DINOv3가 이 데이터에서 더 좋을지는 실험으로 확인해야 합니다.

| 항목 | 제안 |
|---|---|
| 백본 | `facebook/dinov3-vitb16-pretrain-lvd1689m` |
| 입력 | 기존 1024px 사본 → 1024 입력. ViT-B/16의 패치 크기에 맞춤 |
| 학습 | LoRA rank 8 / alpha 16 / dropout 0.1, CLS + 패치 평균 + 패치 최댓값 분류층 |
| 배치 · seed | batch 1 × 누적 8, seed 0. 실제 지원·메모리는 실행 전 짧은 점검으로 확인 |
| Optimizer | AdamW, LoRA `1e-4` / 분류층 `1e-3`, weight decay 0.01 |
| Epochs · 스케줄 | **15 epoch (사용자 확정)**, warmup 1 epoch + 전체 15 epoch에 맞춘 cosine |
| 비교 가중치 · 평가 | 마지막 epoch 가중치, 합산 val 1,319장에서 동일한 기준 선택 절차와 지표 사용 |

**비교의 한계:** EX-01은 30 epoch 스케줄을 12 epoch에서 중단했습니다. EX-02는 백본·입력 크기와 함께 스케줄도 달라지므로, 결과 차이를 백본만의 효과로 해석하지 않습니다. 백본 효과를 더 엄밀히 비교하려면 DINOv2도 15 epoch 전체 스케줄로 별도 실행해야 합니다.

**실행 전 필요한 준비:** 모델 접근 권한 확인, DINOv3용 LoRA 적용 대상 확인, 패치 pooling에서 register 토큰 제외, 저장·재로딩 및 메모리 점검. 현재 코드는 DINOv2용이므로 모델 이름만 바꿔 실행하지 않습니다. 다음 학습과 무거운 준비는 아직 시작하지 않았으며 test는 미평가입니다.

입력 규격과 접근 조건의 근거: [Meta 공식 DINOv3 모델 카드](https://huggingface.co/facebook/dinov3-vitb16-pretrain-lvd1689m). DINOv3 ViT는 패치 크기가 16이며, 가중치 접근에는 모델 페이지의 이용 조건 확인이 필요합니다.
