# Detector · DETR 결과

**담당:** 광빈

데이터셋 v5 (2026-10-17 확정) 기준 결과를 모읍니다. 실행 방법은 [README](README.md)에 있습니다.

## 요약

- 실험: RT-DETR-l / RF-DETR-S / RF-DETR-S + LoRA x 640 · 1024, seed 0, 30 epoch (6개). **대표 결과는 RF-DETR-S 1024와 RF-DETR-S + LoRA 1024**입니다.
- 사진 단위 균형 정확도 (v5 val + val25 합집합 1,319장): RF-DETR-S 1024 82.71%, LoRA 1024 82.50%. LoRA 1024는 전체 정확도(84.84%)와 normal 재현율(84.78%)이 가장 높습니다.
- **conf는 v5 val + val25에서 골랐고, 아래 사진 단위 수치도 같은 셋에서 잰 값입니다.** 기준을 고른 셋으로 다시 채점했으므로 수치가 낙관적일 수 있습니다. test(v5 test, test25)는 아직 한 번도 채점하지 않았습니다.
- 모델 간 차이는 대부분 노이즈 범위입니다. 합집합 균형 정확도의 95% 신뢰구간은 run마다 ±2.7~3.0%p (사진 단위 bootstrap 2,000회)이고, 6개 중 두 run 차이의 신뢰구간이 0을 벗어나는 경우는 RF-DETR-S 1024와 RT-DETR-l 640 (+3.4%p, 95% CI +0.3~+6.5) 하나뿐입니다.

## 채점 기준

| 항목 | 내용 |
|------|------|
| 데이터 | `mendi_damage_v5_20261017`: v5 train / val / test, 2025 평가셋 val25 / test25 (val25 · test25는 640 · 1024 복사본만 있음) |
| 모델 · conf 선택 | v5 val + val25. 두 set의 합집합에서 균형 정확도가 가장 높은 conf 쌍을 0.05 간격 격자 탐색으로 고름. 사진 단위 수치도 같은 셋에서 재므로 낙관적일 수 있음 |
| 최종 채점 | v5 test + test25. 고른 conf를 고정하고(`--fixed-conf`) 마지막에 한 번만. 결과는 이 문서 끝에 따로 추가 |
| 사진 단위 판정 | 사진의 클래스별 최고 score가 기준 이상이면 heel / outsole, 둘 다면 both, 아니면 normal |
| 사진 단위 지표 | 균형 정확도 = 사진이 있는 클래스의 재현율 평균 (both는 0장이라 제외), 전체 정확도, 클래스별 재현율 N / H / O |
| 박스 지표 | v5 val. RT-DETR은 Ultralytics `val`로 best.pt를 다시 채점, RF-DETR은 rfdetr 내장 COCO 평가(`metrics.csv`의 best epoch 행). AP 열은 AP50-95 |
| 공통 설정 | seed 0, 30 epoch, 입력 크기 = 복사본 크기, 그 외 라이브러리 기본값 |

표에 붙일 한 줄은 스크립트가 출력합니다: Box 표는 `train_rtdetr.py` / `train_rfdetr.py`, Photo-level 표의 conf부터 재현율까지는 `eval_image_level.py`.

관찰
- 합집합 균형 정확도는 RF-DETR-S 1024(82.71%)와 LoRA 1024(82.50%)가 가장 높다. LoRA 1024는 전체 정확도(84.84%)와 normal 재현율(84.78%)이 가장 높고, outsole 재현율(72.50%)이 가장 낮다.
- 1024가 640보다 모든 모델에서 균형 정확도가 1~2%p 높다. 박스 지표도 1024가 높다 (RF-DETR-S mAP50-95 0.218 -> 0.248).
- 박스 지표는 세 해상도 비교 모두 RF-DETR-S > RF-DETR-S + LoRA > RT-DETR-l 순이다.
- RF-DETR-S는 best epoch가 이르다 (640에서 9, 1024에서 5). 그 뒤 val mAP가 내려가 과적합 경향이 보인다. LoRA는 18~19, RT-DETR은 21~28.
- 오류는 대부분 정상 사진을 손상으로 판정한 것이다 (합집합 913장 중 outsole 오탐 65~162장, heel 오탐 59~90장). 특히 val25(2025년 사진)에서 normal 재현율이 낮다.
