# Detector · YOLO 결과

**담당:** 보인

데이터셋 v5 (2026-10-17 확정) 기준 결과입니다. 실행 방법은 [README](README.md)에 있습니다.

## 요약

- 기본 학습 2회: **B11 = YOLO11m**, **B26 = YOLO26m**. 둘 다 사전학습 가중치에서 시작, 입력 1024, 50 epoch, seed 0, 같은 설정.
- 사진 단위 균형 정확도 (conf 0.25 고정): v5 val에서 B11 64.4% / B26 66.0%, val25에서 B11 62.1% / B26 61.6%. 1회 학습 결과라 두 모델의 차이는 작은 편이고 우열을 정하기 어렵습니다.
- 두 모델 모두 **outsole 재현율이 13.7~24.6%로 매우 낮습니다.** outsole 사진 대부분을 normal로 판정합니다. 박스 지표에서도 outsole AP50-95가 0.03~0.04로 heel_lining(0.32~0.34)보다 훨씬 낮습니다.
- test(v5 test, test25)는 아직 채점하지 않았습니다.
- 추가 실험(선정 모델 B26 기준)은 [아래](#추가-실험-선정-모델-b26)에 있습니다. **A3(초기 학습률 0.001 → 0.0005)가 conf 0.25 그대로 균형 정확도 +10.0%p(v5 val) / +15.2%p(val25)로 가장 좋고, 전체 정확도도 올랐습니다.** A2(scale 0.25)는 +4.5 / +4.8%p, conf 튜닝(T1)은 +9.6 / +15.3%p지만 같은 셋으로 고르고 잰 낙관적 수치이고 전체 정확도가 내려갑니다. A1(mosaic 0)은 차이 없음, SAHI(T2)는 오히려 내려갑니다.

관찰
- **A3(lr0 0.0005)가 가장 좋습니다.** conf 0.25 그대로 균형 정확도 +10.0%p / +15.2%p, 전체 정확도도 +0.8 / +1.0%p 올라 재학습 실험 중 유일하게 둘 다 오릅니다. outsole 재현율이 크게 오르고 (17.6% → 51.0%, 18.8% → 71.0%), 박스 지표도 outsole AP50이 0.079 → 0.104로 가장 높습니다. normal 재현율은 3.0~5.1%p 내려갑니다. 효과가 크지만 1회 학습이고 이어 학습이 여러 번 있었으므로, 최종 채택 전에 다시 학습해 확인하는 것이 좋습니다.
- **A2(scale 0.25)**: 두 셋 모두 오르지만 (+4.5 / +4.8%p) A3보다 작고, 전체 정확도는 조금 내려갑니다.
- **A1(mosaic 0)**: −0.1 / +1.0%p로 1회 학습의 차이 범위입니다. 채택하지 않습니다.
- **T1(conf 튜닝)**: 균형 정확도는 A3와 비슷하지만 normal을 outsole로 잘못 판정하는 사진이 크게 늘어 (val25 27 → 109장) 전체 정확도가 내려갑니다. 기본선의 outsole 오류 대부분이 낮은 confidence 때문이라는 뜻입니다.
- **T2(SAHI)**: 균형 정확도 −1.5 / −1.9%p. outsole 재현율은 그대로이고 normal을 heel · outsole로 잘못 판정하는 사진만 늘어납니다. 처리 시간도 약 10배라 채택하지 않습니다.
